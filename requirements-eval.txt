# Aeonic token-cost eval — pinned deps for the offline reproduce path.

# dependency in the upstream requirements.txt is not on this path at all —
# so nothing on the eval path depends on an unpinned git ref. Read the scope

# their TRANSITIVE dependencies are not pinned and not hashed. Pillow governs

# bytes. run_manifest.json records the versions actually used for each pass.
